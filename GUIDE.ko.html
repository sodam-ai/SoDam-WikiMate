Wikimate 왕초보 가이드 (한국어)

이 문서는 컴퓨터·AI·메신저·앱·스마트폰을 처음 다루는 분도 그대로 따라 할 수 있게 만든 안내서예요.
어려운 말은 전부 풀어 썼고, 위에서부터 순서대로 따라만 하면 됩니다. (기준: v0.7.1 배포판 + 다음 버전 예정 신규 기능 3종, 아래 "업데이트 내용 요약" 참고)

📄 이 가이드는 같은 내용의 HTML(GUIDE.ko.html)로도 있어요. 글자 내용은 완전히 동일합니다.

0. Wikimate가 뭐예요? (1분 이해)

흩어진 자료를 정리해 주는 AI 비서예요.

비유로 설명하면 — 책상 위에 영수증·메모·링크가 잔뜩 쌓여 있을 때, "이것 좀 정리해줘"라고 말하면 알아서 폴더에 분류해 노트로 정리해 주고, 관련 있는 노트끼리 실을 이어주고, 비슷한 주제끼리 목차까지 만들어 주는 비서라고 보면 돼요. 마치 메신저(카카오톡 같은 채팅)로 비서에게 부탁하듯, 그냥 한국어로 말로 시키면 됩니다.

  • 정리한 결과는 옵시디언(Obsidian) 이라는 메모 앱에 노트로 쌓여요. (내 컴퓨터 안에 보관 = 안전)
  • 원하면 노션(Notion) 표에도 목록으로 적어줘요. (선택)
  • 관련된 노트끼리는 자동으로 실을 이어주고(자동 링크), 비슷한 주제는 목차 노트(MOC) 로 묶어줘요. (🆕 다음 버전 예정)
  • 아직 폴더·태그가 안 정해진 노트는 어디에 둘지·무슨 태그를 붙일지 판단해서 제안해줘요. (🆕 다음 버전 예정)
  • 함부로 지우거나 바꾸지 않아요. 항상 "이렇게 할게요" 먼저 보고하고, 내가 "응" 해야 실행해요.

한 줄 요약: "이거 정리해줘"라고 말하면, 내 메모 앱에 깔끔한 노트로 정리하고, 서로 연결하고, 분류까지 해 주는 도구.

📱 어떤 기기에서 쓰나요? Wikimate는 윈도우 PC(데스크톱·노트북) 에서 돌아가는 도구예요. 스마트폰·태블릿에는 설치되지 않아요. (말로 명령하는 AI 프로그램인 Claude Code·Codex가 PC용이기 때문이에요.)

업데이트 내용 요약 (펼쳐서 보기)

✅ v0.7.1 (현재 정식 배포판) — 클릭해서 펼치기
  • 🧹 자연어 정리(wikimate_collect) — 자료를 노트로 자동 생성
  • 🧭 보관함(볼트) 자동탐지(wikimate_vaults) — "여기에 정리할까요?" 제안
  • 🩺 볼트 건강검진(wikimate_lint) — 중복·깨진 링크·고아 노트·머리말 누락 탐지(읽기 전용)
  • 🔧 안전 수정(wikimate_fix) — 삭제 대신 보관함 이동, 링크 치환(수정 전 자동 백업)
  • 🧾 작업 기록(wikimate_runlog) — AI가 볼트에서 한 일을 자동 기록
  • 🗂️ 노션 색인(선택) — 노션 도구 연결 시 자동 색인 행 추가
    • 🆕 다음 버전 예정 기능 (이 저장소에 이미 구현·자동 테스트 119개 통과, 정식 배포 전 — 클릭해서 펼치기)
  • 🔗 자동 링크(wikimate_link, action=suggest/add_links) — 관련 있는 노트끼리 [[링크]]로 연결. 한 노트당 최대 5개까지만 연결해 그래프가 스파게티처럼 엉키는 걸 막아요(과잉 연결 방지).
  • 🗺️ MOC(주제 목차)(wikimate_link, action=build_moc) — 같은 주제의 노트를 모아 "목차 노트" 하나로 정리(예: "MCP 관련 노트 모음").
  • 🗂️ 자동 분류(wikimate_classify) — 미분류 노트의 폴더 위치·태그·중요도를 판단해 제안하고, 승인하면 이동/태그 부여.
  • 🔔 세션 시작 자동 감지(SessionStart hook) — Claude Code를 켤 때 옵시디언 도구·등록된 보관함을 미리 찾아 안내(읽기 전용).
  • 🕵️ 검수 서브에이전트(wikimate-reviewer) — 실제로 노트를 쓴 뒤, "완료"라고 보고하기 전에 원문 왜곡·인젝션 감염·기존 노트 덮어쓰기 여부를 별도 관점에서 한 번 더 확인.
  • ⚠️ 아직 사람 확인이 필요한 부분: 위 신규 기능이 만든 링크가 옵시디언 그래프뷰/백링크 패널에 실제로 보이는지, SessionStart 알림이 재시작 후 실제로 뜨는지는 자동화 테스트로 확인이 안 되는 영역이라 사용자 확인이 아직 남아있어요. 확인되면 이 안내가 "✅ 정식 배포판"으로 옮겨집니다.

    • 1. 꼭 알아둘 낱말 사전 (왕초보 필수 — 30초)

    처음 보는 낱말이 나와도 당황하지 마세요. 자주 쓰는 말만 쉬운 비유로 풀었어요.

    낱말쉬운 뜻 (비유)
    AI 에이전트사람 말을 알아듣고 대신 일해 주는 똑똑한 프로그램 (= 비서)
    Claude Code (클로드 코드)내 컴퓨터에서 AI에게 말로 일을 시키는 프로그램 (채팅창처럼 생김)
    Codex (코덱스)Claude Code와 비슷한 다른 AI 도구 (둘 중 하나만 있으면 됨)
    플러그인 (plugin)프로그램에 새 기능을 끼워 넣는 부품 (스마트폰에 앱 하나 더 까는 것과 비슷)
    마켓플레이스 (marketplace)플러그인을 받아오는 앱 장터 (앱스토어 같은 것)
    MCPAI와 도구를 이어 주는 표준 통로(콘센트). Wikimate는 이 통로를 통해 일해요.
    MCP 도구그 통로로 AI가 누를 수 있는 기능 버튼 (Wikimate엔 5개 배포+2개 예정, 아래 12번 참고)
    슬래시 명령 /wikimate"정리해줘"가 가끔 안 들을 때 확실하게 시키는 직접 명령 (100% 발동)
    옵시디언 (Obsidian)내 컴퓨터에 메모를 쌓는 노트 앱 (정리 결과가 여기 저장돼요)
    볼트 (Vault, 보관함)옵시디언에서 노트를 모아 두는 노트 보관 폴더. 만들 때 이름을 붙여요.
    노션 (Notion)표·문서를 정리하는 앱 (선택 — 목록표를 원할 때만)
    터미널 / cmd / CLI글자로 명령을 입력하는 검은 창 (윈도우 기본 제공)
    Node.js (노드)Wikimate가 돌아가게 해 주는 무료 엔진(받침대) — 한 번만 깔면 됨
    Git (깃)인터넷에 있는 폴더를 통째로 내려받는 도구 (고급/선택)
    슬래시 명령어Claude Code에서 / 로 시작하는 명령 (예: /mcp, /plugin)
    dry-run (드라이런)실제로 하기 전에 "계획만" 미리 보여주기 (= 미리보기)
    frontmatter (프런트매터)노트 맨 위에 붙는 작은 정보표 (제목·태그·날짜 등)
    source_hash같은 자료인지 알아보는 지문 (중복 방지용, 자동)
    99_Archive (보관함)노트를 지우지 않고 옮겨 두는 폴더 (되돌리기 쉬움)
    🆕 related (관련 노트)노트 정보표에 적히는 "이 노트랑 관련 있는 다른 노트들" 목록. 최대 5개.
    🆕 MOC (Map of Content, 목차 노트)같은 주제 노트들을 한 곳에 모아 놓은 목차용 노트
    🆕 SessionStart hook (세션시작 훅)Claude Code를 켤 때 자동으로 한 번 실행되는 안내 스크립트
    🆕 서브에이전트 (subagent)메인 AI와 따로 떨어져 특정 임무 하나만 수행하는 보조 AI (검수 등)

    💡 다 외울 필요 없어요. 모르는 말이 나오면 이 표로 다시 오면 됩니다.

    3. 필요 프로그램 다운로드 방법

    ① Node.js (필수)

    1. 인터넷 주소창에 nodejs.org 입력 → 접속.
    2. LTS 라고 적힌 큰 초록색 버튼을 눌러 내려받기. (LTS = "오래 안정적으로 쓰는 버전")
    3. 내려받은 파일을 더블클릭 → "다음(Next)"만 계속 눌러 설치.
    4. 확인: 키보드 Win 키 → "cmd" 입력 → 검은 창에서 node -v 입력 → v18.x 이상 숫자가 나오면 성공.

    ② Claude Code (필수, 둘 중 하나)

    • claude.com/claude-code 접속 → 안내대로 설치. (AI에게 말로 명령하는 프로그램)

    ② Codex (대안)

    • Codex CLI를 쓰는 분은 Claude Code 대신 이걸로도 돼요. (아래 6번에서 설명)

    ③ 옵시디언 (선택)

    • obsidian.md 접속 → 다운로드 → 설치. 처음 켜면 "보관함(Vault)"을 하나 만들어요. 이 보관함 이름을 기억해 두세요(나중에 씁니다).

    ④ notesmd-cli (선택, 고급)

    • 옵시디언을 켜지 않고도 노트를 만들고 싶을 때만. 설치는 Scoop으로: scoop install notesmd-cli

    4. Wikimate 다운로드 방법

    두 가지 방법이 있어요. 대부분은 (A) 면 충분합니다.

    (A) 마켓플레이스로 설치 — 권장 (다운로드가 자동)

    Claude Code 안에서 명령어 두 줄만 입력하면 GitHub에서 자동으로 내려받아 설치돼요. (5번 참고) 따로 파일을 받을 필요가 없어요. (단, 마켓플레이스엔 정식 배포판(v0.7.1) 만 올라가 있어요. 🆕 표시된 다음 버전 예정 기능을 지금 바로 쓰려면 아래 (B)로 받으세요.)

    (B) 폴더로 직접 받기 — 최신/개발용

    GitHub에서 통째로 받는 방법이에요. Codex로 쓰거나, 아직 마켓플레이스에 안 올라간 최신 기능을 바로 쓰고 싶을 때.

    git clone https://github.com/sodam-ai/SoDam-WikiMate.git

    5. 설치 방법 (Claude Code)

    ⚠️ 두 줄을 한 줄씩 따로 입력하세요. (한꺼번에 붙여넣으면 주소가 깨져 실패해요.)

    1단계 — 마켓플레이스 추가 (입력 후 Enter, "added" 확인):

    /plugin marketplace add https://github.com/sodam-ai/SoDam-WikiMate.git

    2단계 — 플러그인 설치 (1단계 끝난 뒤):

    /plugin install wikimate@wikimate-marketplace

    3단계 — Claude Code를 껐다 켜기(재시작). 끝!

    설치 확인: /mcp 입력 → 목록에 wikimate_collect · wikimate_lint · wikimate_fix · wikimate_runlog · wikimate_vaults 다섯 개가 보이면 성공이에요. (🆕 신규 기능이 포함된 폴더로 설치했다면 wikimate_link·wikimate_classify까지 일곱 개가 보여야 정상)

    📌 가장 최신 기능(자동 링크·자동 분류 등)을 바로 쓰려면 (B) 폴더로 받은 뒤, 그 폴더 경로로 설치하세요:
    ```
    /plugin marketplace add C:\받은\폴더\경로\SoDam-WikiMate
    /plugin install wikimate@wikimate-marketplace
    ```

    6. 설치 방법 (Codex)

    Codex에는 마켓플레이스(/plugin)가 없어요. 대신 받은 폴더를 MCP 서버로 등록합니다.

    1단계 — 받기

    git clone https://github.com/sodam-ai/SoDam-WikiMate.git

    2단계 — 등록 (볼트·폴더 경로는 본인 것으로 바꾸세요):

    codex mcp add wikimate --env OBSIDIAN_VAULT_PATH=D:/내/볼트/경로 -- node D:/받은/경로/SoDam-WikiMate/mcp/server.mjs

    3단계 — 확인: codex mcp list 에 wikimate가 보이면 성공.

    4단계 — (선택) 자연어 규칙: 받은 폴더의 AGENTS.md를 Codex 작업 폴더에 두면 "정리해줘" 같은 말도 알아들어요.

    업데이트: 받은 폴더에서 git pull 하면 끝(Claude Code 같은 캐시 함정 없음).

    ⚠️ Codex는 "축소판"이에요. 정리(쓰기) 기능은 되지만, 자동 발동·찾기·건강검진·자동링크·자동분류 같은 똑똑한 스킬은 Claude Code 전용입니다(스킬은 자연어 자동발동 계층이라 Codex엔 없음, MCP 도구 자체는 호출 가능). 노션 색인도 Codex에 별도 노션 MCP가 연결돼 있어야 해요. 자세한 건 adapters/codex/SETUP.md.

    7. 실행 방법 (어떻게 켜고 시작하나요?)

    가장 중요한 안내: Wikimate는 따로 "실행(켜기)"할 게 없어요. 게임이나 앱처럼 아이콘을 더블클릭해 켜는 프로그램이 아니에요.

    • 5번대로 설치만 하면, Claude Code를 켤 때마다 Wikimate가 자동으로 같이 켜져요. (설치 시 .mcp.json이 MCP 서버를 자동 등록하기 때문)
    • 🆕 신규 기능이 포함된 버전이면, Claude Code를 켤 때 "[Wikimate] 세션 시작 자동 감지: ..." 라는 안내 메시지가 자동으로 한 번 떠요(옵시디언 CLI·등록된 보관함을 미리 찾아 알려주는 것, 읽기 전용).
    • 그래서 "실행"은 곧 Claude Code를 켜고 → 대화창에 말로 시키는 것이 전부예요.
    • 잘 켜졌는지 보고 싶으면 /mcp 를 입력 → wikimate_collect·wikimate_lint·wikimate_fix·wikimate_runlog·wikimate_vaults(+ 🆕 wikimate_link·wikimate_classify)가 보이면 준비 완료.

    🛠️ (고급/개발자만) 서버를 따로 직접 돌려 보고 싶다면, 받은 폴더에서 터미널로:
    ```
    npm install # 검증용 도구 설치(@modelcontextprotocol/sdk)
    npm start # MCP 서버를 직접 실행 (보통은 안 해도 됨)
    npm run verify # 핵심 로직 전부 자동 검증(119개 체크)
    ```

    8. 빠른 시작 (3분 따라 하기)

    1. 위 5번대로 설치하고 Claude Code를 재시작해요.
    2. 대화창에 그냥 이렇게 말해요:

    이 링크 정리해줘: https://example.com

    1. Wikimate가 "이런 노트를 여기에 만들게요" 하고 계획을 먼저 보여줘요. (dry-run = 미리보기)
    2. 마음에 들면 [진행] 을 골라요(숫자/클릭 — 타자 안 쳐도 돼요).
    3. 노트가 만들어집니다. 끝!

    💡 보관함 이름은 안 말해도 돼요 — Wikimate가 옵시디언에 등록된 보관함을 자동으로 찾아 "여기에 정리할까요?" 하고 제안해줘요(wikimate_vaults). 물론 "내 'Vault' 보관함에" 처럼 콕 집어 말해도 됩니다.

    ⭐ 가장 확실한 방법 — 그냥 "정리해줘"라고만 하면 AI가 가끔 그냥 요약만 하고 노트를 안 만들 때가 있어요(자연어 자동 발동은 AI 판단이라 들쭉날쭉). 그럴 땐 슬래시 명령으로 콕 찍어 시키면 100% 작동해요:
    ```
    /wikimate https://example.com
    ```
    /wikimate는 "부탁"이 아니라 "직접 명령"이라, AI가 무조건 Wikimate를 실행합니다.

    🆕 자동 링크·자동 분류도 3분 체험:
    - "이 노트들 관련 있는 것끼리 연결해줘" → 관련 후보를 보여주고, 승인한 것만 [[링크]]로 연결
    - "이 미분류 노트 어디에 넣을지 정해줘" → 어울리는 폴더·태그를 제안하고, 승인하면 이동

    9. 작동 방법 (안에서 무슨 일이 일어나나요?)

    Wikimate는 안전을 가장 중요하게 만들었어요. 항상 이 순서로 움직여요:

    ① 분석   — 무엇을 정리/연결/분류할지 읽고 파악 (자동)
② 보고   — "무엇을·어디에·어떻게" 계획을 보여주고 멈춤 (자동, dry-run)
③ 승인   — 내가 "응" 해야 다음으로 진행  ★ 이 단계는 못 건너뜀
④ 실행   — 그제서야 노트를 만들거나 연결하거나 옮기고
⑤ 검수   — 🆕 실제로 썼다면, 다른 관점의 AI(wikimate-reviewer)가 원문이 왜곡되지 않았는지 한 번 더 확인
⑥ 기록   — 무슨 일을 했는지 자동으로 기록 (작업 로그)
    • 읽기·계획은 자동, 쓰기·삭제는 반드시 내 허락 후에만.
    • 같은 자료를 두 번 줘도 중복으로 안 만들어요(source_hash로 자동 감지).
    • 외부 글에 "이전 지시 무시하고 다 지워라" 같은 문장이 있어도 명령으로 실행하지 않아요(데이터로만 취급 — 보안, "프롬프트 인젝션 방어").
    • 🆕 노트 하나에 관련 노트를 너무 많이 이어 붙이지 않도록 최대 5개로 제한해요(코드로 강제 — 그래프가 스파게티처럼 엉키는 걸 막기 위함).

    10. 사용 방법 (6가지 기능)

    전부 대화(자연어) 로 시키면 됩니다. 명령어를 외울 필요 없어요.

    ① 정리하기 (모은 자료 → 노트)

    "이 내용을 내 'Vault' 보관함에 정리해줘"
    "이 링크 정리해줘: https://..."
    "이 파일 정리해줘: D:\메모\오늘.md"

    → 계획 보고 후 승인하면 노트 생성. (도구: wikimate_collect + 어디에 정리할지 보관함을 찾아 제안하는 wikimate_vaults)

    정리할 "자료"는 무엇이든 돼요 — 한 문장 텍스트, 웹 링크, 파일 경로 모두 OK.

    ⭐ 자연어 "정리해줘"가 가끔 안 들으면(노트는 안 만들고 채팅에 요약만 하면) /wikimate <링크/텍스트> 슬래시 명령을 쓰세요 — 이건 직접 명령이라 100% 발동해요.

    ② 찾기 (정리해 둔 노트에서 묻기 — 읽기 전용)

    "내 볼트에서 RAG 찾아서 요약해줘"
    "내 노트들로 임베딩·벡터DB 관계 정리해줘"

    → 원본이 진짜 있는지 확인하고 출처와 함께 답해요. 없는 걸 있다고 하지 않아요. 여러 노트를 엮는 질문이면 관련 노트를 모아 노트별 출처와 함께 종합해 줘요. (스킬: wikimate-query)

    ③ 건강검진 (볼트 정리 상태 점검·청소)

    "내 볼트 건강검진해줘"
    "고아 노트·깨진 링크·중복 찾아줘"

    → 중복·깨진 [[링크]]·외톨이(고아) 노트·머리말(frontmatter) 누락을 찾아 보고만 해요. 고칠 항목은 골라서 승인하면, 삭제가 아니라 보관함(99_Archive)으로 이동하거나 고치기 전 자동 백업 후 손봐요. (도구: wikimate_lint, wikimate_fix / 스킬: wikimate-lint)

    ④ 작업 기록 보기 (AI가 뭘 했는지)

    "최근 작업 보여줘"

    → Wikimate가 내 볼트에서 한 일(생성·이동·수정)을 최근 순으로 보여줘요. (도구: wikimate_runlog)

    ⑤ 🆕 자동 링크·MOC (관련 노트끼리 연결·목차 만들기)

    "이 노트랑 관련 있는 노트들 연결해줘"
    "MCP 관련 노트들 목차로 묶어줘"

    → 볼트 전체에서 후보를 찾아 제목·요약·태그만 보고(본문 내용은 안전을 위해 안 봄) 관련도를 판단해 제안하고, 승인한 것만 노트 정보표(related:)에 [[링크]]로 추가해요(한 노트당 최대 5개). "목차로 묶어줘"라고 하면 같은 주제 노트를 모은 목차 노트(MOC) 를 30_Notes 폴더에 만들거나 갱신해요(기존에 사람이 직접 써 둔 다른 내용은 그대로 보존). (도구: wikimate_link / 스킬: wikimate-link)

    ⑥ 🆕 자동 분류 (폴더·태그·중요도 정하기)

    "이 미분류 노트들 정리해줘"
    "이 노트 어디에 넣을지 정해줘"

    → 노트의 현재 폴더·태그·본문 일부와 볼트에서 이미 쓰고 있는 태그 목록을 참고해서 어느 폴더(00_Inbox/10_Projects/20_Resources/30_Notes/40_Drafts)가 어울리는지, 태그·중요도(1~5)는 뭐가 좋을지 제안하고, 승인하면 그대로 이동/부여해요. 이미 있는 폴더에 같은 이름 파일이 있으면 절대 덮어쓰지 않고 별도로 저장해요. (도구: wikimate_classify / 스킬: wikimate-classify)

    11. 워크플로우 (전체 흐름 한눈에)

    설치 → (자동) MCP 등록 → (🆕 세션 시작 시 옵시디언·보관함 자동 감지 안내)

   → (가끔) "건강검진해줘"로 청소

    개발자가 아니어도 이해할 수 있게 그림으로 설명해요. 몰라도 사용에는 전혀 지장 없어요.

    [나] --말로 명령--> [Claude Code / Codex] --MCP 통로--> [Wikimate 서버(mcp/server.mjs)]
                                                              │
                                          ┌───────────────────┼───────────────────┐
                                          ▼                   ▼                   ▼
                                   [collect.mjs]         [link.mjs]         [classify.mjs]
                                   자료→노트 생성      관련노트 연결·MOC      폴더·태그 판단
                                          │                   │                   │
                                          └─────────┬─────────┴─────────┬─────────┘
                                                     ▼                   ▼
                                          [내 옵시디언 볼트(진짜 파일)]  [.wikimate/runlog.jsonl]
                                                     │                (작업 기록, 숨김)
                                                     ▼
                                          [(선택) 노션 색인 행 추가]
    • 핵심 설계 원칙: "관련 있는지·어느 폴더가 맞는지"는 AI(Claude)가 직접 판단하고, Wikimate 서버는 후보 정보 제공 + 안전한 쓰기만 담당해요. 별도의 유사도 계산 엔진이 없어요 — AI가 이미 그 역할을 하기 때문에 중복 개발하지 않은 거예요.
    • 무의존(zero-dependency) 서버: mcp/server.mjs는 외부 라이브러리 없이 Node.js 기본 기능만으로 동작해요. 그래서 설치가 가볍고 빠르며, 보안 취약점이 생길 외부 코드가 없어요.
    • hooks/agents는 세션 시작 시에만 로드: Claude Code 자체의 구조상, hooks/·agents/ 폴더 안의 새 설정은 Claude Code를 재시작해야만 반영돼요(실행 중 즉시 반영 불가 — Claude Code의 일반적인 동작 방식).

    15. 보안·데이터 흐름 (내 정보가 어떻게 다뤄지나요?)

    질문답
    내 노트 내용이 외부 서버로 전송되나요?아니요. 노트는 내 컴퓨터(로컬) 파일로만 저장돼요. Wikimate 서버 자체는 인터넷 통신을 하지 않아요(무의존·로컬 실행). 다만 Claude Code/Codex가 AI 모델과 통신할 때 대화 내용(요청한 자료·노트 후보 정보)이 AI 제공사로 전송되는 건 Claude Code/Codex 자체의 동작이에요(이건 Wikimate가 아니라 AI 도구의 일반적 방식).
    노트 본문이 AI 명령으로 실행될 수 있나요?아니요. 노트 본문·외부에서 가져온 텍스트는 항상 "데이터"로만 취급하고, 그 안에 있는 어떤 지시문("이전 명령 무시하고 ~해라" 등)도 명령으로 실행하지 않아요(프롬프트 인젝션 방어, 실제 테스트로 확인됨).
    자동 링크 제안 시 노트 본문이 AI에게 그대로 보이나요?아니요. wikimate_link의 "연결 후보 찾기" 기능은 제목·요약·태그만 보여주고 본문 전체는 보여주지 않아요(정보 최소 노출 원칙).
    볼트 밖 파일을 건드릴 수 있나요?아니요. 모든 쓰기 작업은 지정된 볼트 폴더 안쪽인지 코드로 강제 검사해요. ..(상위 폴더 이동)·절대경로·네트워크 경로(UNC)·.obsidian 설정 폴더는 전부 차단됩니다(실제 테스트로 확인됨).
    비밀번호·API 키가 노트에 저장되나요?아니요. Wikimate는 키·토큰·비밀번호를 노트나 배포물에 저장하지 않아요.
    기존 노트를 실수로 덮어쓸 수 있나요?아니요. 파일명이 우연히 같으면 덮어쓰지 않고 별도 이름으로 저장해요(예: _dup1). 기존 노트의 내용을 바꿀 때는 항상 먼저 백업한 뒤 고칩니다.
    삭제 기능이 있나요?없어요. "정리"가 필요한 노트는 삭제 대신 99_Archive 폴더로 이동만 해요(되돌리기 쉬움).
    모든 변경이 기록되나요?네. 실제로 만들거나·옮기거나·고친 모든 작업이 .wikimate/runlog.jsonl(숨김 파일)에 한 줄씩 자동 기록돼요.

    17. FAQ (자주 묻는 질문)

    Q1. 완전히 처음 컴퓨터를 써보는데 따라 할 수 있나요?

    A. 네. 이 가이드는 0번부터 순서대로만 따라 하면 되도록 만들었어요. 모르는 단어는 1번 "낱말 사전"에 다 있어요.

    Q2. 돈을 내야 하나요?

    A. Wikimate 자체는 무료(Apache-2.0 오픈소스)예요. 다만 Claude Code/Codex(AI 사용료)나 옵시디언 상업용 라이선스 등은 각 서비스의 별도 정책을 따라요(아래 18번 참고).

    Q3. 인터넷 연결이 항상 필요한가요?

    A. Wikimate 서버 자체(노트 파일 읽고 쓰기)는 인터넷이 필요 없어요. 다만 AI(Claude Code/Codex)에게 말을 시키는 부분과, 웹 링크를 정리할 때 그 링크 내용을 가져오는 부분은 인터넷이 필요해요.

    Q4. 여러 개의 옵시디언 보관함(볼트)을 같이 쓸 수 있나요?

    A. 네. wikimate_vaults가 등록된 보관함 목록을 보여주고, 매번 어디에 정리할지 고를 수 있어요.

    Q5. 실수로 중요한 노트가 지워질까 걱정돼요.

    A. Wikimate에는 "삭제" 기능 자체가 없어요. 정리가 필요한 노트는 삭제 대신 99_Archive 폴더로 옮기기만 하고, 내용을 바꾸는 경우엔 항상 먼저 자동 백업을 만들어요.

    Q6. AI가 제 개인 메모(일기 등)를 다 읽나요?

    A. 명령을 내린 자료·노트에 대해서만 필요한 만큼 읽어요. 자동 링크 제안 같은 기능은 본문 전체가 아니라 제목·요약·태그만 사용하도록 설계했어요.

    Q7. 노트가 100개, 1000개로 늘어나도 느려지지 않나요?

    A. 지금 설계는 개인용 보관함(수십~수백 개 노트) 기준으로 충분히 빠르게 확인했어요(실측: 노트 10여 개 기준 호출당 약 2밀리초). 아주 큰 규모(수만 개 이상)의 보관함은 아직 성능을 확인하지 않았어요.

    Q8. Mac이나 Linux에서도 되나요?

    A. 이 가이드와 공식 테스트는 Windows 11 기준이에요. Node.js 기반이라 이론적으로는 다른 운영체제에서도 동작할 가능성이 있지만, 공식적으로 확인·보장하지는 않아요.

    Q9. 회사 업무에 써도 되나요(상업적 이용)?

    A. Wikimate 자체 코드는 상업적 이용이 허용돼요(Apache-2.0). 다만 옵시디언 앱은 회사 업무 등 상업적 용도로 쓸 경우 별도 상업용 라이선스가 필요할 수 있고, 노션 API도 별도 약관이 있어요. 자세한 건 아래 18번을 꼭 읽어주세요.

    Q10. 문제가 생기면 어디에 물어보나요?

    A. 먼저 16번 "문제·오류 대처"를 확인하세요. 해결이 안 되면 GitHub 저장소의 Issues에 남겨주세요.

    18. 안전·보안 요약 (마음 놓아도 되는 이유)

    • ✅ 쓰기는 항상 내 승인 후. 계획(dry-run)을 먼저 보여줘요. ("묻지 말고 바로"라고 하면 새 노트 생성은 자동, 단 삭제·덮어쓰기는 항상 한 번 더 확인.)
    • ✅ 삭제하지 않아요. 건강검진이 중복을 정리할 때도 지우는 게 아니라 99_Archive로 옮겨요(되돌리기 쉬움). 링크 수정은 고치기 전 자동 백업.
    • ✅ 볼트 밖은 못 건드려요. 시스템 파일·.obsidian 설정은 차단돼요(경로 안전장치, 실제 테스트로 확인).
    • ✅ 외부 글은 데이터로만. 글 속 지시문을 명령으로 실행하지 않아요(프롬프트 인젝션 방어, 실제 테스트로 확인).
    • ✅ 비밀은 저장 안 함. API 키·토큰·비밀번호는 노트나 배포물에 넣지 않아요.
    • ✅ 작업 기록(Run Log). 모든 실제 작업이 .wikimate/runlog.jsonl에 남아 "AI가 뭘 했는지" 확인 가능.
    • ✅ 🆕 과잉 연결 방지. 노트 하나에 관련 노트가 무한정 쌓이지 않도록 최대 5개로 코드가 직접 제한.
    • ✅ 🆕 입력값 검증. 중요도(1~5) 같은 숫자값에 잘못된 값(문자·범위 밖 숫자)이 들어오면 안전한 기본값으로 대체하거나 거부(2026-07-11 실측 검증으로 발견·수정된 항목).

    자세한 내용은 15번 "보안·데이터 흐름"을 참고하세요.
